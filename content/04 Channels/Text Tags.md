# Text Tags

Name each channel (up to **16 characters**) so you know what you're hearing. Default tag: bank number + channel-in-bank number.

## Steps
1. `Hold` → channel number → `Pgm/E`
2. Choose **Edit Tag** → `Pgm/E`
3. Turn the [[Scroll Control]] to pick each character.
4. Move the cursor with **`6/>`** (right) and **`4/<`** (left).
5. Press `Pgm/E` to save.

| Key | Action |
|---|---|
| `.Clr` once | Delete last character |
| `.Clr` twice | Clear the whole tag |
| `L/O` | Cancel without saving |

> [!tip]
> With only a knob for letters, tagging hundreds of channels is slow. [[PC Programming]] is much quicker.
