# Close Call Menu

**Open:** `Func` → `Hold` (in Scan or Search). Scroll, `Pgm/E` to select, `.Clr` to go back.

## Close Call Mode
Off · DND · Pri · Close Call Only — see [[Close Call#Close Call modes]].

## Close Call Bands
Choose which bands Close Call watches (in all modes). Select a band → *C-Call Band On/Off*.

| Key in CC Only | Band | Range |
|---|---|---|
| `1` | VHF-Low | 25 – 88 MHz |
| `2` | Air | 108 – 137 MHz |
| `3` | VHF-High | 137 – 174 MHz |
| `4` | MIL-Air | 225 – 320 MHz |
| `5` | UHF | 320 – 512 MHz |
| `6` | 800MHz | 806 – 960 MHz |

## Close Call Alert
| Option | Does | Default |
|---|---|---|
| Alert Beep | Beeps on a hit | On |
| Alert Light | Flashes the backlight on a hit | On |

## Scan Hits
Include the Close Call Hits bank in Scan. *Scan Hits On / Off* — **default Off**. (Also toggled with `.Clr` while scanning.)

## Set Delay
−10, −5, 0, 1–5 s, **default 2 s**. Shared with all searches — see [[Delay]].

## CTCSS/DCS Search
*Search On / Off*, **default On**. Shared with all searches — see [[CTCSS and DCS]].
