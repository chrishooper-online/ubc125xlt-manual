# PC Programming

Typing 500 channels and tags with a knob is slow. Over USB a computer can program every channel and setting, and back up what's stored.

## Connect
- Use the supplied USB cable.
- Plug into a port on the computer itself, not a hub.
- The first time, Windows asks for a **driver**.

> [!note] Charging vs programming
> The scanner charges only when **off**. Programming happens with it **on**.

## Driver and software
Uniden's manual points to **Butel** for the European driver and software: `butel.nl/ubc125xlt`. The driver is free; the program is paid.

### ARC125 (Butel)
The software Uniden recommends for this model. Paid, roughly £25–£30 from UK radio retailers.
- Supports both the US **BC125AT** and the European **UBC125XLT**
- Memory editor with cut / copy / paste
- Import from CSV and RadioReference; export to CSV
- Driver included

> [!tip] Alternatives
> The UBC125XLT is the European twin of the US BC125AT, so tools for that model are commonly used too — check each one says it supports the UBC125XLT before relying on it. Back up with whatever you use before making big changes.

## Workflow
1. Read the scanner into the software first — this is your backup. Save the file.
2. Edit channels, tags, tones and settings on screen.
3. Write back to the scanner.
4. Keep the file with your [[Channel Log Template|channel log]].
