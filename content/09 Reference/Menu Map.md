# Menu Map

Menus: [[Display and Charge Menu]] · [[Channel Menu]] · [[Priority Scanning]] · [[Search Menu]] · [[Close Call Menu]]

Every menu and shortcut on one page. Turn the [[Scroll Control]] to move, `Pgm/E` (or press the knob) to select, `.Clr` to go back.

```
Func + Power ──── Display/Charge menu
  ├─ Set Backlight    Always Off* | Always On | On with Squelch | On with Keypress | Keypress+Squelch
  ├─ Set Contrast     1–15
  └─ Set ChargeTime   1–14 h (14*)

Hold → ch# → Pgm/E ── Channel menu
  ├─ Enter Frequency
  ├─ Edit Tag         16 chars
  ├─ Set CTCSS/DCS    Off* | CTCSS → tone | DCS → code | CTCSS/DCS Search | No Tone
  ├─ Set Modulation   AM | FM
  ├─ Set Delay        −10 | −5 | 0 | 1 | 2* | 3 | 4 | 5 s
  ├─ Set Priority     On | Off*
  ├─ Delete Channel
  └─ Clear Bank

Func + 1/PRI ──── Priority menu
  └─ Priority Off* | Priority DND | Priority Scan | Priority Plus | Exit

Func + Pgm/E (in search) ── Search menu
  ├─ Set Delay        −10 … 5 s (2*)
  ├─ CTCSS/DCS Search Search On* | Search Off
  ├─ Program Limits   Search Bank 1–10 → Lower / Upper
  └─ Review Lockouts  Review Freq L/O | Unlock All

Func + Hold ───── Close Call menu
  ├─ Close Call Mode  Off | DND | Pri | Close Call Only
  ├─ Close Call Bands VHF-Low | Air | VHF-High | MIL-Air | UHF | 800MHz → On/Off
  ├─ Close Call Alert Alert Beep (On*) | Alert Light (On*)
  ├─ Scan Hits        On | Off*
  ├─ Set Delay        −10 … 5 s (2*)
  └─ CTCSS/DCS Search Search On* | Search Off

* = default
```

## Direct shortcuts
| Keys | Does |
|---|---|
| `Func` → `3/Step` | Step size (while holding a frequency) |
| `Func` → `9/Mod` | Toggle AM/FM (while holding a frequency) |
| `Func` → `7/Beep` | Key beep on/off |
| `Func` → `L/O` | Keypad lock on/off |
| `Func` → `Srch/Svc` | [[Service Search]] |
| `Func` → knob press | Squelch |
| Knob press | Volume |
| Hold `L/O` | Unlock all |
| Hold `1` / `2` + power on | [[Band Plans\|Band Plan]] 1 / 2 |
| Hold `2` + `9` + `Hold` + power on | [[Factory Reset]] |
