# Glossary

**AM / FM** — Amplitude / frequency modulation. Air band uses AM; most other two-way radio uses FM. See [[Modulation and Step]].

**Band plan** — The scanner's table of default steps and modes per frequency range. See [[Band Plans]].

**Bank** — A group of channels or search ranges you can switch on or off. See [[Banks]].

**BNC** — Bayonet antenna connector on top of the scanner.

**Birdie** — A signal generated inside the receiver itself. See [[Troubleshooting#Birdies]].

**Channel** — A memory slot holding a frequency and its settings. 500 available.

**Close Call** — Uniden's RF capture: detects strong nearby signals and tunes straight to them. See [[Close Call]].

**CTCSS / DCS** — Sub-audible tone or digital code that opens squelch only for matching transmissions. See [[CTCSS and DCS]].

**Delay** — How long the scanner waits after a transmission before moving on. See [[Delay]].

**DND (Do-Not-Disturb)** — Priority or Close Call checks happen only between transmissions, never interrupting one.

**Hold** — Stay on the current channel or frequency. See [[Hold and Manual Selection]].

**Lockout** — Skip a channel or frequency. Temporary (until power-off) or permanent. See [[Lockouts]].

**PMR446** — Licence-free UHF handheld radios used across Europe and the UK (446 MHz).

**Priority** — A channel checked every 2 seconds while scanning. See [[Priority Scanning]].

**Repeater** — A high-sited station that rebroadcasts on an output frequency what it hears on an input frequency.

**Scanning** — Cycling through stored channels.

**Searching** — Stepping through a frequency range looking for activity.

**Simplex** — Talk and listen on the same frequency; no repeater.

**Squelch** — The threshold that mutes noise until a signal arrives. See [[Volume and Squelch]].

**Step** — Spacing between frequencies tried during a search. See [[Modulation and Step]].

**Tag (alpha tag)** — A channel's text name, up to 16 characters. See [[Text Tags]].

**Turbo Search** — Automatic faster search on bands with 5 kHz steps.
