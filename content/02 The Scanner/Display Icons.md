# Display Icons

64 × 128 dot-matrix LCD with orange backlight. Not every icon shows at once.

```
 HOLD                       TL/O
 Channel Name
 CH001  162.5250          ↓
 FM   PRI+   C  254.1
 BNK 1 2 3 4 5 6 7 8 9 0 C     P  F
```

| # | Indicator | Meaning |
|---|---|---|
| 1 | Top text line | Channel name (Scan/Hold) · search bank name · `Quick Search` · `Close Call Hits` · `Close Call` |
| 2 | Second line | `Scan` scrolling · `CC Search` · channel number + frequency · searching frequency |
| 3 | **P** | This is a [[Priority Scanning\|priority channel]] |
| 4 | `BNK` / `SVC` / `SRC` / `BND` + digits | Banks or bands enabled for Scan / Service Search / Custom Search / Close Call Only. The active one flashes. **C** = Close Call Hits bank |
| 5 | `AM` / `FM` | Modulation |
| 6 | `PRI` / `PRI+` | Priority Scan or Priority DND / Priority Plus |
| 7 | Tone/code | CTCSS/DCS received — blinks during tone search, solid if programmed |
| 8 | Close Call icon | Close Call Priority or Do-Not-Disturb active |
| 9 | ↑ / ↓ | Scan/search direction |
| 10 | Battery | Low battery |
| 11 | Key | [[Keypad Lock and Key Beep\|Keypad lock]] on |
| 12 | Bars | Signal strength |
| 13 | `TL/O` / `L/O` | Temporary / permanent [[Lockouts\|lockout]] |
| 14 | `HOLD` | Holding on a channel or frequency |
| 15 | **F** | Function mode active |
