# Keys and Controls

## Layout
- **Top:** antenna (BNC), headset jack, [[Scroll Control]] knob
- **Side:** USB port
- **Front keypad:** `Hold/CC`, `Scan`, `Srch/Svc`, `L/O`, power/backlight, `Pgm/E`, number keys `0`–`9`, `.Clr`, `Func`

## Function mode
Most keys have a second job printed beneath them. Press **`Func`** and an **F** appears on the display for **3 seconds** — press the second key within that window. Press `Func` again to cancel early.

## Key reference

| Key | Press | `Func` + key |
|---|---|---|
| `1/PRI` | Enter 1 | [[Priority Scanning\|Priority]] menu |
| `2` | Enter 2 | — |
| `3/Step` | Enter 3 | Step menu ([[Modulation and Step]]) |
| `4/<` | Enter 4 · cursor left when editing a [[Text Tags\|tag]] | — |
| `5` | Enter 5 | — |
| `6/>` | Enter 6 · cursor right when editing a tag | — |
| `7/Beep` | Enter 7 | Toggle [[Keypad Lock and Key Beep\|key beep]] |
| `8` | Enter 8 | — |
| `9/Mod` | Enter 9 | Toggle [[Modulation and Step\|modulation]] |
| `0` | Enter 0 | — |
| `.Clr` | Decimal point · space in a tag · clear / back | — |
| `Func` | Enter / leave Function mode | — |
| `Hold/CC` | Hold the current channel or frequency · release Hold and resume · monitor an entered frequency · jump to an entered channel number | [[Close Call Menu]] |
| `Scan` | Start or resume [[Scanning Stored Channels\|Scan]] | — |
| `Srch/Svc` | Start [[Custom Search]] | Start [[Service Search]] |
| `L/O` | Once: temporary lockout · twice quickly: permanent lockout · on a locked item: unlock · press and hold: unlock all | [[Keypad Lock and Key Beep\|Keypad lock]] on/off |
| Power/backlight | Hold: power on/off · press: backlight on/off | [[Display and Charge Menu]] |
| `Pgm/E` | Select / confirm · open a channel by number | [[Channel Menu]] · quick-save a found frequency |

> [!tip] The knob does menus
> Turn the [[Scroll Control]] to move through menu items; pressing it is the same as `Pgm/E`.

## Number keys as bank switches
In Scan and Search modes, the number keys toggle banks on and off rather than typing digits — see [[Banks]].
