# Priority Scanning

Lets you keep a close watch on your most important channels.

## 1. Mark priority channels
One per bank, so up to 10.

`Hold` → channel → `Pgm/E` → **Set Priority** → *Priority On* → `Pgm/E`

**P** shows on the display for that channel.

## 2. Choose a priority mode
In Scan or Search: **`Func` → `1/PRI`**, choose, `Pgm/E`. **Default: Off.**

| Mode | Icon | Behaviour |
|---|---|---|
| Priority Off | — | No priority checks |
| Priority DND | `PRI` | Checks priority channels every 2 s **only when not receiving** — never interrupts what you're hearing |
| Priority Scan | `PRI` | Checks every 2 s **even during a transmission** |
| Priority Plus | `PRI+` | Scans **only** priority channels in enabled banks |
| Exit | | Leave the menu |

Priority works in Scan, Search and Hold — but not in Close Call Only mode.

> [!warning] `Priority Scan No Channel`
> No priority channel exists in an enabled bank, so priority is set back to Off.

> [!tip]
> **Priority DND** is the friendly choice: important channels still break in between calls, but conversations aren't cut off mid-sentence.
