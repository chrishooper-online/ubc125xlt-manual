# Keypad Lock and Key Beep

## Keypad lock
**`Func` → `L/O`** toggles it. The display shows `Keypad Lock On` or `Keypad Lock Off`, and a key icon appears while locked.

While locked, only these work: `Func`, `Hold`, the power/backlight key, and the [[Scroll Control]] (volume only).

## Key beep
**`Func` → `7/Beep`** toggles the confirmation tone (**default: on**). It beeps on correct entries and sounds an error tone on mistakes.
