# Search Menu

**Open:** `Func` → `Pgm/E` while in Service, Custom or Quick Search (or their Hold).

| Item | Options | Default | Shared with |
|---|---|---|---|
| Set Delay | −10, −5, 0, 1, 2, 3, 4, 5 s | 2 s | [[Close Call Menu\|Close Call]] — see [[Delay]] |
| CTCSS/DCS Search | Search On / Off | On | Close Call — see [[CTCSS and DCS]] |
| Program Limits | Search Bank 1–10 → Lower / Upper | Factory ranges | Custom Search only — see [[Custom Search]] |
| Review Lockouts | Review Freq L/O · Unlock All | — | All search modes — see [[Lockouts]] |
| Step | Default / 5 / 6.25 / 8.33 / 10 / 12.5 / 20 kHz (band-dependent) | Band plan | Close Call — see [[Modulation and Step]] |
| Modulation | AM / FM | Band plan | Close Call — see [[Modulation and Step]] |

> [!note]
> The manual says step and modulation can be set from this menu but doesn't print the exact item names. Both can also be changed directly with `Func` → `3/Step` and `Func` → `9/Mod` while holding a frequency.
